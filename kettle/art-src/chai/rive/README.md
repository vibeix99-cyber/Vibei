# Chai

Chai, the Kettle focus-timer mascot, as a Rive file: `chai.riv`.

Built only from shapes, keyframe animations and one state machine. There's no scripting,
so it runs offline in a web app (an unsigned build is fine, because there are no scripts
to sign).

## Artboard

- Name: `Chai`
- Size: **1312 × 1586**.
  - Chai's body keeps the reference images' proportions and position (they're 992 × 1586),
    centred with 160 px added on each side for the cheering arms.
  - Through the bounce, wave and pose changes, Chai stays at least 40 px inside each
    side edge.

## Switching poses

State machine: **`Chai`** (the artboard's default; it starts on its own).

| Value | Pose |
|---|---|
| `0` | reading |
| `1` | sipping |
| `2` | cheering |

There are two ways to set the pose, and both use those values:

- **View-model number `pose`** (preferred). View model `Chai`, default instance
  `Default`. Its default is `-1`, which means "not set, use the input".
- **State machine number input `pose`** (fallback). Default `0`.
  - Rive marks state-machine inputs as deprecated, but they still work.
  - The view model wins whenever it holds 0, 1 or 2. The input is used only while the
    view model is `-1` or not bound.

Every pose change goes through rest: the current pose blends to rest, then rest blends to
the new pose. Cheering is entered and left through an extra step: the arms swing up from
the shoulders while still short, then reach up (and fold back the same way on the way out).

```js
// @rive-app/canvas (check the names against your runtime version)
const r = new rive.Rive({
  src: "chai.riv", canvas, autoplay: true,
  stateMachines: "Chai", autoBind: true,
});
// preferred:
r.viewModelInstance.number("pose").value = 2;
// fallback:
r.stateMachineInputs("Chai").find(i => i.name === "pose").value = 2;
```

## What moves

| Pose | Motion |
|---|---|
| Rest (always on) | Breathing on a 3.6 s cycle. A blink at alternating 4.6 s / 5.4 s gaps. |
| Reading | Leaf sways on a 4 s cycle. One page turn every 12 s. |
| Sipping | Two steam wisps rise and fade in staggered 3 s cycles. One sip every 6 s: prepare, lift, contact, hold, return. |
| Cheering | Two soft squash-and-stretch hops every 2.8 s. A small arm wave. Sparkles pop in turn. The yuzu follows a beat late. |

State machine layers: `Pose`, `Action` (each pose's own loop), `Breath`, `Blink`.

## Part names

These are the shapes and groups to look up by name:

- **Body:** `chai` (root group; the bounce), `breath`, `body` (`bodyLower`,
  `bodyLowerLight`), `groundShadow`.
- **Head:** `head`, `headBase`, `headShade`, `muzzle`, `muzzleShade`, `muzzleSheen`,
  `sheen`, `fur` (`fur1`–`fur3`), `earL` / `earR`.
- **Face:**
  - Eyes: `eyeL` / `eyeR` switch between `eyeLOpen`, `eyeLHalf`, `eyeLClosed` and
    `eyeLClosedHappy` (and the R versions).
  - Around the eyes: `lidL` / `lidR`, `eyeLShine` / `eyeRShine`, `browL` / `browR`.
  - The rest: `nose`, `noseHighlight`, `blushL` / `blushR`.
  - Mouth: `mouth` switches between `mouthSmile` and `mouthOpen`.
- **Arms and paws:**
  - Arms: `armL` / `armR`, each with one tapered shape (`armLLimb` / `armRLimb`).
  - Paws: `pawL` / `pawR`, on mounts `pawLMount` / `pawRMount` that share the arms'
    shoulder pivots.
  - Feet: `footL` / `footR`.
- **Yuzu:** `yuzu` (pose tilt), `yuzuSway` (the cheering lag), `yuzuFruit`, `yuzuStem`,
  `leaf`.
- **Props:**
  - Book: `book`, with the turning page `bookPageTurn`.
  - Mug and steam: `carry` (moves the mug and paws for the sip), `mug`, `steam1` /
    `steam2`.
  - Sparkles: `sparkleL` / `sparkleR`.

## Files

- `chai.riv`: the built file (also written to `build/chai.riv`).
- `scene.rml`: the Rive source. It's generated by `tools/gen_scene.py`, so edit the
  generator rather than the RML, then run `python tools/gen_scene.py`.
- `refs/`: the approved design images.
